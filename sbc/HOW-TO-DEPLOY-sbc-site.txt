SBC Global Foundation — put the new website and editor live on Netlify (drag and drop)
======================================================================================

The site comes in 5 small zip files (sbc-site-part-1-of-5.zip ... part-5-of-5.zip) so each one downloads easily.
You need ALL FIVE. Together they are the whole website, videos included.

Before you start (only once)
----------------------------
1. In the SBC Supabase project, open "SQL Editor" and make sure these files have been run, in order:
   0005_groups_and_videos.sql, 0006_video_storage.sql, 0007_owner_and_bank.sql, 0008_design_features.sql,
   0009_gallery_captions.sql, 0010_about_people.sql
   (they are in the project under supabase/migrations/). Do this BEFORE using the new editor.
2. In Supabase: Project Settings -> API. Copy the "Project URL" and the "anon / public" key.
   NEVER use the "service_role" or "secret" key.

Step 1 - Put the 5 parts into ONE folder
----------------------------------------
1. Make an empty folder, for example "sbc-site" on your Desktop.
2. Extract each of the 5 zip files INTO that same folder, one after another:
   - Windows: right-click a zip -> Extract All -> choose the sbc-site folder. Repeat for each part.
     (If asked about replacing files, there is nothing to replace: choose Yes / Replace.)
   - Mac: double-click each zip, then drag its contents into the sbc-site folder (Merge if asked).
3. When you are done, the sbc-site folder should contain: index.html, config.js, content.js, support.js,
   _headers, a folder called "admin", and a folder called "assets" (with about 70 files, including 3 .mp4 videos).

Step 2 - Fill in config.js
--------------------------
1. Open the file "config.js" (inside the sbc-site folder) in Notepad / TextEdit (plain text). It looks like:
      window.SBC_CONFIG = { supabaseUrl: '', anonKey: '' };
2. Put your two values between the quotes, for example:
      window.SBC_CONFIG = { supabaseUrl: 'https://abcdxyz.supabase.co', anonKey: 'eyJ...your public key...' };
3. Save the file.

Step 3 - Drag it onto Netlify
-----------------------------
1. Sign in to Netlify. Open the site (sbcfoundation-site) -> "Deploys".
2. Drag the WHOLE sbc-site folder onto the box that says "Drag and drop your site output folder here".
   IMPORTANT: a drag-and-drop deploy replaces the whole site with exactly what is in the folder.
   Anything missing from the folder (for example the videos) will be missing from the live site.
3. Wait for "Published".

Step 4 - Check it
-----------------
- Website:  https://sbcfoundation-site.netlify.app/        (Programmes, Gallery, About and Give pages; the School Supplies video plays)
- Editor:   https://sbcfoundation-site.netlify.app/admin/   (should show the Sign in screen with a round seal)
- If the editor says "Not set up yet": config.js is empty or has a typo. Fix it and drag the folder again.
- If an old design still shows: close the browser tab and open the link again (it is a cached copy).

Later, once GitHub is connected, Netlify can update itself and you will not need to drag folders any more.
